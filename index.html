IDR per SDR control chart

Each point is the monthly cost of one SDR in the selected currency, so a higher value means a weaker currency. The dashed lines are the control limits. A red point lies beyond them: the currency moved further from its own average than normal variation explains.

Connect a workbook

Drop an Excel file here (.xlsx), or use the buttons below.

A web page cannot watch a file on your disk by itself. Choose the workbook once. In Chrome or Edge the refresh button then re-reads that same file after you save it in Excel. In other browsers, choose the file again after saving. Nothing is uploaded; the file is read in your browser.
